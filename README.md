# Next Time

Next Time is a field guide to **Lattice Thinking**. Start with a puddle. Water can reach a bird directly when it drinks or indirectly through soil, roots, and fruit. Follow either route beyond the bird and the garden looks different again. [Read the Next Time field guide](https://next-time-lattice-thinking.my.canva.site/)

The garden study works through 36 possible transfers. Use the numbered entries to check where routes split, meet, or return to an earlier point. Some entries describe an existing transfer in finer detail. Each describes a possibility. Establishing which route water took in a particular garden would require observations. [Explore the interactive garden atlas](https://mayhem82.github.io/next-time/)

The Lattice Atlas calls an examination of one surface a *mesh*. A *lattice* stacks those surfaces. The *Atlas* records what their relationships reveal.

The worked garden records show all five operational stages of the Modular Audit and Yield for Humans Enforcement Mechanism, from preserving the two written lists through deciding whether a notice can be issued. They include the independent review procedure and the operating steps. [Read the garden gateway records](https://mayhem82.github.io/next-time/gateways/)

## Run locally

From the repository root, run the following command and open `localhost:8000` in your browser.

```sh
python -m http.server --directory dist 8000
```
