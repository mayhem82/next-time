# Next Time

Next Time is an interactive guide to **Lattice Thinking**. Start with a puddle. Water can reach a bird directly when it drinks or indirectly through soil, roots, and fruit. Follow either route beyond the bird and the garden looks different again. [Explore Next Time](https://mayhem82.github.io/next-time/)

The garden study works through 36 possible transfers. Use the numbered entries to check where routes split, meet, or return to an earlier point. Some entries describe an existing transfer in finer detail. Each describes a possibility. Establishing which route water took in a particular garden would require observations.

The MAYHEM Lattice Atlas calls an examination of one surface a *mesh*. A *lattice* stacks those surfaces. The *Atlas* records what their relationships reveal. A published investigation shows the same approach applied to governance. [Read the worked MAYHEM Lattice Atlas](https://mayhem82.github.io/taylors-arm-flying-fox-investigation/findings/lattice-atlas.html)

## Run locally

From the repository root, run the following command and open [localhost on port 8000](http://localhost:8000/).

```sh
python -m http.server --directory dist 8000
```
